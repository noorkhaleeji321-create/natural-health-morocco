# خطة تسريع تحميل متجر Natural Health Morocco وتحسين تجربة الزبون الجديد

تهدف هذه الخطة إلى حل مشكلة الظهور البطيء أو الفارغ للمنتجات عند دخول أي زبون جديد، وتسريع تحميل صور سلايدر الهيرو (Hero Slider) بشكل فوري وسلس دون تأخير.

---

### قرارات المستخدم المؤكدة (Confirmed Decisions):
- **تحسين سرعة ظهور المنتجات**: إظهار هيكل تحميل فوري (Skeleton Screen) أنيق ومتحرك في شبكة المنتجات يملأ الشاشة فوراً لحين وصول بيانات الخادم، مع تسريع جلب البيانات.
- **تسريع سلايدر الهيرو**: تحميل مسبق فوري (`link rel="preload"` و `fetchpriority="high"`) للصورة الأساسية الأولى مع تحسين استجابة السلايدر.

## 2. خطوات التنفيذ التفصيلية

### أ. إنشاء مكون الهيكل التحميلي الفوري (`ProductCardSkeleton`):
- إنشاء مكون مخصص `src/components/ProductCardSkeleton.tsx` يطابق أبعاد وبنية `ProductCard` (مساحة الصورة، العنوان، السعر، الزر).
- استخدامه فوراً عندما تكون حالة `isLoading` مفعلة أو عند بدء المتجر لأول مرة، بحيث يرى الزبون 4 بطاقات محملة بشكل طبيعي وأنيق بأسلوب Shimmer بدلاً من شاشة فارغة تماماً.

### ب. ترقية `StoreContext.tsx` وإضافة حالة التحميل الأولية (`isLoadingProducts`):
- إضافة متغير حالة `isLoadingProducts` لتمييز الزبون الجديد الذي لا يملك أي كاش مسبق.
- تسريع التنسيق بين Local Node.js REST API (`/api/bootstrap`) و Firebase:
  - الاعتماد الفوري على بيانات Local API السريعة لعرض المنتجات في أجزاء من الثانية.
  - إبقاء مزامنة Firestore في الخلفية لضمان استمرارية التحديثات دون تأخير العرض الأولي للمستخدم.

### ج. تسريع تحميل سلايدر الهيرو (Hero Slider):
- إضافة وسم `<link rel="preload" as="image" href="/assets/images/hero_spices_1793739545710.jpg" fetchpriority="high" />` في ملف `index.html`.
- إضافة `fetchpriority="high"` و `loading="eager"` للشريحة الأولى في `HeroSlider.tsx`.
- ضبط الشريحة الأولى لتبدأ بالظهور فوراً دون انتظار تفعيل السلايدر التلقائي.

### د. تحديث أقسام الصفحة الرئيسية (`BestSellersSection` و `NewArrivalsSection` و `ProductsPage`):
- تمرير حالة `isLoading` وعرض مكونات `ProductCardSkeleton` بسلاسة أثناء التحميل.
- في حالة انتهاء التحميل ووجود منتجات، تظهر المنتجات مباشرة دون أي وميض أو تأخير.

## 3. التحقق والاختبار (Verification)
1. **اختبار التصفح كزبون جديد**: مسح الكاش والتخزين المحلي واختبار فتح المتجر في نافذة تصفح خاصة (Incognito).
2. **فحص سرعة سلايدر الهيرو**: التأكد من أن الصورة الأولى تظهر فوراً مع الشعار وعناصر الثقة.
3. **فحص تجميع الكود**: تشغيل `compile_applet` و `lint_applet` للتأكد من خلو المشروع تماماً من أي أخطاء برمجية.
4. **المزامنة مع المستودع**: رفع كافة التحديثات إلى فرع GitHub الرئيسي (`origin master`).
